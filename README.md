# SQL Data Analytics Project
Exploratory data analysis and advanced analytics in SQL, from the first look at the data to a customer report and a product report. The data and every query.
    <img width="1740" height="672" alt="image" src="https://github.com/user-attachments/assets/77ed0e4f-a4fc-4449-92f8-0cbb01847567" />

The project has two parts, and the scripts follow them:

Exploratory data analysis, scripts 01 to 06 from the tables and dates to the big numbers and the top performers.
Advanced analytics, scripts 07 to 13, deeper with trends, running totals, performance, part-to-whole and segments. Two reports close the project, one for customers and one for products.
